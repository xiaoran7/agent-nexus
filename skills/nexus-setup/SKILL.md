# Agent-Nexus 零负担协同防护接入指南 (nexus-setup)

本指南遵循最高原则：**Agent-Nexus 绝不能给目标项目产生任何一点负担。**
业务项目不需要新增任何文件，不需要修改 `.gitignore`，更不需要在 `AGENTS.md` 里塞满复杂的规矩说明。

Nexus 的定位就像道路上的红绿灯和交警系统，是建在操作系统/开发机全局的，车（AI 助手）开进任何道路（项目）都自然受到保护，而不是要求每条路上都立牌子写交规。

---

## 1. 核心铁律：项目零负担与零污染

1. **业务项目零文件、零改动（默认且强烈推荐）**：
   - 目标项目**无需创建 `.mcp.json`**；
   - 目标项目**无需修改 `.gitignore`**；
   - 目标项目**严禁强行修改 `AGENTS.md` 塞入样板规则**；
   - 整个接入过程对业务代码仓库完全透明，Git 状态保持 100% 纯净。

2. **全局一次配置，全机所有项目自动受保护**：
   - 只要当前开发机全局装好了 Hook 并启动了后台中枢；
   - 无论你在哪个项目、开多少个 Claude Code / Codex / ZCode 会话并发干活，防撞车系统全自动在后台保驾护航。

3. **全自动防撞车与自动释放（无需手动声明）**：
   - **自动检测与拦截**：当助手 A 正在改某个文件时，助手 B 如果也去改这个文件，会被系统自动挡下，并清楚告知对方是谁、大概还要等多久；
   - **智能区域锁（大文件不卡壳）**：如果是大型文件且两人改的是不同区域（例如页面头部 vs 底部数据流），系统自动放行，互不干扰；
   - **提交自动解锁（零感释放）**：助手改完一旦执行 `git commit` 或 `git push`，系统秒级自动解开文件锁并叫醒后面排队的助手，不需要任何人手动点释放；
   - **跨工作树（Git Worktree）自动识别**：哪怕开在不同的工作树分支上，系统会自动认出它们是同一个项目，杜绝跨分支撞车。

---

## 2. 标准接入方式：全局零侵入（1 分钟完成）

这是官方推荐的唯一默认方式，**对所有业务项目 0 污染**。

### 第一步：启动 Nexus 协同中枢后台服务
在 Agent-Nexus 本地根目录下运行：

```bash
# 启动后台守护服务（默认监听 4100 端口）
node src/cli.js start
```

服务启动后，打开浏览器 `http://127.0.0.1:4100/` 即可看到中文协同大屏。

### 第二步：给开发工具装上全局防护钩子（只做一次）
执行以下命令，把防护钩子写到当前用户的全局配置（如 `~/.claude/settings.json`）中：

```bash
# 注册全局 PreToolUse 钩子
node "<Agent-Nexus路径>/src/cli.js" hook:install
```

### 第三步：大功告成！直接正常写代码
**目标项目什么都不用动！**
现在你可以直接在任意项目里开多个会话写代码：
- 修改同名文件冲突？系统自动拦截；
- 写完执行 `git commit`？锁自动秒解；
- 浏览器打开大屏，能实时看到各会话的施工状态。

## 3. 可选进阶：需要项目长期备忘录或跨会话提问时

如果你希望在 Claude 对话里手动使用 MCP 工具（比如查看项目长期备忘录、或者让会话 A 向会话 B 发结构化消息提问），才需要配置 MCP。即使配置，也必须保证**零污染**：

### 选项 A（推荐）：配置在用户的全局 MCP 设置中
直接把 Nexus MCP 服务写进用户的全局配置中，业务项目依然不加任何文件。

### 选项 B：在目标项目生成本地 `.mcp.json`
若确实需要在特定项目根目录放 `.mcp.json`：
1. 使用安全合并命令，绝不破坏项目中已有的 AOCI 等其他配置：
   ```bash
   node "<Agent-Nexus路径>/src/cli.js" mcp:install "<目标项目路径>"
   ```
2. **严防污染 Git**：
   若该项目没有全局 ignore `.mcp.json`，必须确保不会把这个本地文件 commit 到远端；万一被 git 跟踪，执行 `git rm --cached .mcp.json` 即可解挂。
3. **切勿修改项目的业务文档**：
   不要在项目的 `README.md` 或 `AGENTS.md` 里硬塞 Nexus 规章制度。

## 4. 常见问题大白话速查

| 问 | 答 |
|---|---|
| **我新开了一个项目，需要做什么配置？** | **什么都不用做！** 全局钩子装好后，任何项目里的会话都会被自动保护，零配置开工。 |
| **为什么修改文件时被拦住了？** | 说明另一个会话正在改同一个文件。命令行里会显示对方名字和预估等待时间；等对方 `git commit` 或做完后，你就会被自动唤醒。 |
| **改大文件的不同地方也会被拦吗？** | 不会！Nexus 支持锚点区域锁，改不同模块互不干扰，安全并发。 |
| **我和同事拉取代码会看到 Nexus 的垃圾文件吗？** | 完全不会！零文件入库原则保证了远端仓库没有任何 Nexus 痕迹。 |
